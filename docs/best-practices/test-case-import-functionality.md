# Testcase Import Functionality

---


The Test Case Import feature allows users to **reuse existing test cases by appending their steps to the current test case**. Imported steps are added **below the current step sequence**, enabling faster test creation and reducing repetitive configuration work.

:::info Key Benefit
This helps maintain consistency across scenarios while minimizing rework when building similar or extended test flows.
:::
